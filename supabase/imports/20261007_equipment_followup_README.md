3. Карточки появятся в админке как черновики, без цен, с временной заглушкой. Добавить фото, выбрать главное, удалить заглушку, проверить статус и опубликовать.

Статус «Под заказ» — редакционное значение по умолчанию, не проверенное наличие.

MOD 1 GR, не двухгрупповой модуль с одним подключённым краном. Размеры/масса модуля и крана разделены. Состав поставки и ABR не заявлены.

433×1056×745 не подтверждены для поддона и исключены. Точный артикул и чертёж нужны для габаритов; не назначены размеры поддона с ринзером, ABR, материал и комплектность.
