# Дополнение описаний MUVNA

Запустить **20261015_muvna_content.sql** в SQL Editor нужного проекта Supabase после миграции аксессуаров и первоначального импорта каталога. Перед запуском рекомендуется резервная копия. Скрипт не запускается приложением автоматически.

- 110 карточек / 161 артикул. Подготовлены названия, описания и доступные характеристики на русском, английском и казахском.
- Заполняются только отсутствующие и пустые поля. Существующие названия, описания и характеристики не заменяются, даже если они устарели или написаны на другом языке. Непустой русский текст из первоначального импорта останется прежним.
- Цены, остатки, цвета, фотографии, состав вариантов, категории и статус публикации не меняются. Черновики не публикуются.
- Карточки определяются по точному набору артикулов, а не по изменяемой ссылке. Если товар удалён или варианты перегруппированы, весь запуск отменяется с ошибкой. Сначала нужно сверить состав каталога, а не отключать проверку.
- Все изменения выполняются одной транзакцией. Повторный запуск не меняет уже заполненные данные. Короткий таймаут блокировки предотвращает долгое ожидание занятой карточки; при ошибке изменений не будет.
- Обновлённым карточкам меняется `updated_at`: открытый ранее редактор нужно перезагрузить, чтобы не затереть новое содержимое.
- Текстовые характеристики поддерживают `{ "ru": "…", "en": "…", "kz": "…" }`; старые числовые и строковые значения остаются прежними. Вместе с SQL следует использовать обновлённый `app/accessories/model.ts`, который отображает локализованные значения. В стафф-редакторе такие значения представлены JSON.

В конце SQL возвращает число заполненных переводов, обновлённых наборов характеристик и изменённых карточек. При повторном запуске ожидаются нули, если после первого запуска поля снова не очищали.

## Источники и ограничения

`20261015_muvna_content_sources.md` — источники по артикулам. Основные сведения: прайс Muvna.pdf, уточнения заказчика, международный сайт MUVNA, региональные магазины бренда и карточки продавцов. Ссылки, сохранённые прежним импортом, приведены для прослеживаемости и не означают, что все их утверждения перенесены в характеристики.

`20261015_muvna_content_review.md` — спорные параметры, которые не добавлены. Совместимость с кофемашинами, неподтверждённые размеры, комплектация, время сохранения температуры и характеристики похожих модификаций не угадывались. Для товаров без точной технической карточки дано краткое описание назначения. Казахские тексты желательно дополнительно вычитать носителю языка перед публикацией.

Для воспроизводимого изменения дополнения редактировать `build_muvna_content.mjs` / `muvna_content.template.sql`, затем выполнить:

```sh
node supabase/imports/build_muvna_content.mjs
```

Генератор создаёт SQL, JSON и два отчёта; к базе он не подключается.
