## Артикулы по объёму

| Товар / цвет | Объём | Артикул |
| --- | --- | --- |
| Tivat, серый | 160 / 220 / 320 мл | BZ2282 / BZ2283 / BZ2284 |
| Контейнер, чёрный | 250 / 500 / 750 г | GC2299 / GC2300 / GC2301 |
| Контейнер, серый | 250 / 500 г | GC2314 / GC2315 |

Пользователь подтвердил, что серого контейнера 750 г нет. В карточке этот объём недоступен при выборе серого цвета. Связи хранятся в существующем JSON `volume_options.skuByVariant`; миграция схемы не нужна. Редактор сохраняет их, поиск витрины и стафф-панели учитывает их.

FB2298 занят старым архивным Mobius: перед назначением объединённому товару архивной записи добавляется суффикс `-ARCHIVED-<id>`. Архивная карточка, фотографии, цены и история не удаляются. GC2301 также остаётся в старом архивном контейнере и указан в объёме новой объединённой карточки.

## Не назначено

«Новый аксессуар», slug `accessory-55c2ea5c-7b23-4b67-aef1-4755e9917c4a`: нет данных для идентификации, цена 0. Автоматический ACC-код сохранён внутри базы, на витрине служебные ACC-UUID не отображаются.

Перед восстановлением снимка сначала сверить текущие значения с `after`: нельзя затирать более поздние изменения сотрудников. В резервной копии сохранены исходные варианты, объёмы и точные пары before/after.
