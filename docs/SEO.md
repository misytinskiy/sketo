# SEO каталога

Перед production-сборкой задайте `SITE_URL` в окружении сервера и сборки:

```dotenv
SITE_URL=https://your-production-domain.example
```

Замените пример основным доменом сайта. Допускается только origin без пути, query
и fragment. Адрес никогда не вычисляется из присланного посетителем Host.
В development без настройки используется `http://localhost:3000`.
Production-сборка без `SITE_URL` завершается ошибкой вместо публикации неверных ссылок.

- Карточки кофе: `/catalog/{slug}`.
- Карточки оборудования: `/equipment/{slug}`.
- `/catalog/equipment` и вложенные адреса постоянно перенаправляются (308) на `/equipment`.
- Title/description и Open Graph/Twitter формируются из актуального товара на сервере.
- В редакторе раздел «SEO: поиск и превью ссылок» позволяет задать title/description
  отдельно для RU/EN/KZ. Пустое поле возвращает автоматическое значение.
- Для превью используется изображение товара; inline-заглушки и blob-адреса исключены.
- JSON-LD содержит Product и BreadcrumbList. Данные берутся из видимого содержимого;
  выдуманные цены, наличие, отзывы и рейтинги не добавляются. Наличие разметки само
  по себе не гарантирует расширенный результат поисковика.
- `/sitemap.xml` включает публичные разделы и только опубликованные товары с реальным
  `updated_at`. Кеш данных сбрасывается существующими тегами публикации/архивации/
  удаления/переименования. Отдельный долгоживущий кеш XML не используется.
- `/robots.txt` объявляет sitemap; кабинет и вход закрыты от обхода, а их страницы
  дополнительно имеют `noindex` и проверку авторизации.

Язык сейчас выбирается cookie: без cookie поисковик получает RU. Отдельных языковых
URL нет, поэтому hreflang не добавляется. Независимая индексация EN/KZ потребует
отдельной задачи по языковым маршрутам.

Изменение slug товара пока не сохраняет историю прежних адресов: редиректы в этой
задаче устраняют только дубли маршрутов оборудования.

Проверки: `node --test tests/*.test.mjs`, `npx tsc --noEmit`, `npm run lint`,
production-сборка и HTTP-проверка HTML карточек, 404, редиректов, robots и sitemap.
