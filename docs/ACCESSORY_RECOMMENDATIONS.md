# Рекомендации аксессуаров

## Актуальное расширение: неизвестный метод не означает несовместимость

Самостоятельные товары (включая кофемолки) допускаются к кружкам, подносам, полотенцам, ложкам и другим товарам без метода приготовления. Явное противоречие методов по-прежнему исключает кандидата. Наличие кофемолки в составе набора исключает повторную кофемолку; сама категория «наборы» больше не является запретом.

Добавлены уход, коврики, дозирование, свободные игольчатые WDT, молочные инструменты, кофеварки, наборы и подарки. В смешанных категориях проверяется конкретный товар: плоский коврик допускается, станция с неподтверждённой посадкой — нет; стакан для дозирования допускается, кольцо — нет; WDT с диаметром или вращающейся посадкой исключается. Размерозависимые детали не объявляются совместимыми без данных. Правило уникальности типов сохранено.

Высота рекомендаций задаётся самой высокой из трёх наложенных grid-панелей. Неактивные панели невидимы и inert (не получают фокус и скрыты от скринридера), но участвуют в расчёте высоты. Переключение 2/3 карточек не меняет размер блока; переносы текста и смена языка учитываются без обрезания.

## Актуальное ограничение: один товар каждого типа

Внутри каждого этапа категория аксессуара уникальна, в том числе при запасном подборе. Кофе считается одним типом: максимум один лот в «Приготовлении». Добор другой модели весов, чайника и т. п. больше не разрешён. Цель — до трёх разных типов; при нехватке подходящих типов правило уникальности важнее минимального количества. Разнообразие моделей между разными страницами сохранено. Это правило заменяет описанный ниже добор несколькими моделями одной категории и несколькими лотами кофе.

## Обновление: разнообразие, заполнение и кофе

Следующие правила заменяют ограничения первой версии ниже:

- Цель — три позиции на этап. Сначала разные дополняющие категории, затем дополнительные модели из этих категорий. В последнюю очередь допустимы альтернативы категории текущего товара с соответствующей подписью. Ограничения «один товар на категорию» больше нет; подарки также получают общий подбор.
- Рейтинг учитывает совпадение способа приготовления, близость ценового диапазона KZT и стабильный хеш пары текущий товар/кандидат. Это разнообразит страницы без случайных перестановок при перезагрузке. Это не измеренная вероятность покупки.
- Отсутствие фотографии не исключает товар: используется стандартная заглушка. Неподходящие привязки цвета/объёма по-прежнему отфильтровываются.
- В приготовлении первая позиция зарезервирована для опубликованного кофе в наличии. Один дополнительный кешируемый запрос `getCoffeeRecommendationItems` получает карточки и характеристики метода. Кеш инвалидируется вместе с кофе.
- Явное совпадение метода приоритетно, явное противоречие исключает лот. При неизвестном методе подпись нейтральная: «Попробуйте этот лот кофе». Категории profiles/microlot/decaf не доказывают соответствие методу. Если аксессуаров мало, раздел добирается другими лотами кофе.
- Минимум два возможен при наличии двух подходящих опубликованных товаров. Пустой/распроданный ассортимент нельзя заполнить фиктивными или неподходящими позициями. Тесты проверяют три позиции во всех этапах при достаточном ассортименте.
- Размерозависимые детали по-прежнему не подставляются ради количества.
- Декорация подключена из `public/photo/catalog/accArt.png`. Изменения схемы БД не нужны.

Остальные описания ниже отражают исходную версию; при расхождении действуют правила этого обновления.

Подбор вычисляется на сервере в `app/accessories/recommendations.ts` из публичного каталога. В браузер передаются только отобранные позиции. Дополнительных запросов при переключении этапов нет. Схема базы не меняется.

Это объяснимые правила по текущему товару, не персонализация и не оценка вероятности покупки. Поведение посетителей не собирается.

## Правила первой версии

- Только опубликованные товары из `getAccessories`, с вариантом в наличии и доступным фото.
- Исключаются текущий товар, его категория и повторы ID.
- Способ приготовления читается из `brewing_method`, включая переводы и формат редактора `localized-attribute`. Для однозначных категорий есть запасные правила. Рекламное описание и название не используются как доказательство совместимости.
- Противоречащие способы приготовления исключаются. Без известного способа предлагаются только общие категории: весы, хранение, посуда.
- Кофемолка предлагается только при подтверждённом совпадении способа приготовления. К наборам кофемолки не предлагаются. Известное содержимое набора исключает повторные инструменты.
- Размерозависимые товары, фильтры, корзины, портафильтры, темперы, разравниватели и другие категории вне явного разрешённого списка не рекомендуются. Одинаковый диаметр не доказывает совместимость.
- Весы приоритетнее хранения; для пуровера чайник приоритетнее воронки. Совпадение способа приготовления добавляет приоритет. Равные оценки разрешаются стабильно по ID, без случайных перестановок.
- Максимум три позиции на этап, не больше одной из каждой категории. Пустой этап остаётся пустым; если подходящих дополнений вообще нет, секция скрыта. Для подарков секция также скрыта.

Каждая рекомендация содержит краткое назначение на RU/EN/KZ, а не обещание технической совместимости. Complete your setup удалена: рекомендации находятся только в блоке ритуала.

## Как улучшать дальше

Для точного подбора деталей нужны проверенные связи совместимости (модель кофемашины, стандарт крепления, формат фильтра), а не только диаметр. Для более точного ранжирования общих товаров полезны структурированные сценарии использования, полный состав наборов и редакторские приоритеты. Сейчас одинаково оценённые модели не ранжируются по качеству или популярности: таких данных нет.

Персонализацию и оптимизацию конверсии имеет смысл добавлять отдельно, когда появятся корректные события просмотров, переходов и заказов и согласованные правила работы с этими данными.

Проверки: `node --test tests/accessory-recommendations.test.mjs tests/accessories-public.test.mjs`.
